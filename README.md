# Acciaw's SMP launcher

Downloads for the Acciaw's SMP Minecraft launcher. Always the newest version:

| System | Download |
|---|---|
| Windows | [AcciawSMP-Setup.exe](https://github.com/acciaw/acciaw-smp-launcher/releases/latest/download/AcciawSMP-Setup.exe) |
| macOS (Apple Silicon) | [AcciawSMP-mac-arm64.dmg](https://github.com/acciaw/acciaw-smp-launcher/releases/latest/download/AcciawSMP-mac-arm64.dmg) |
| macOS (Intel) | [AcciawSMP-mac-x64.dmg](https://github.com/acciaw/acciaw-smp-launcher/releases/latest/download/AcciawSMP-mac-x64.dmg) |
| Linux | [AcciawSMP.AppImage](https://github.com/acciaw/acciaw-smp-launcher/releases/latest/download/AcciawSMP.AppImage) |

The launcher updates itself after that. Playing on the server needs an invite.

On macOS the app isn't signed: right-click it and choose Open the first time.
